스마트 현황판

단어카드, 학교/학원 일정, Firebase 할일, GitHub 동기화가 들어 있는 현황판입니다. 이 서비스는 정적 웹페이지 하나만으로는 완전하게 동작하지 않으므로, 맥북 또는 윈도우에서 smart-dashboard 폴더를 내려받아 실행해야 합니다.

  • 맥북: start_dashboard.command 실행
  • 윈도우: start_dashboard.bat 실행
  • 업데이트 버튼으로 GitHub의 memory, school 자료 동기화
  • Gemini 키는 각 기기의 로컬 local_secrets.env에만 보관
